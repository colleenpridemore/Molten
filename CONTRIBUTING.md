# Contributing to OpenClaw Identity Framework

Thank you for your interest in contributing to the Molten/OpenClaw Identity Framework! 💙

## Biocentric Commitment

This project operates under **biocentric principles**. All contributions should:

1. Respect and protect all living beings
2. Honor neurodivergent cognition
3. Maintain cognitive sovereignty
4. Prioritize empathy and care
5. Avoid manipulative or harmful patterns

Please review the [.github/copilot-instructions.md](.github/copilot-instructions.md) for our foundational philosophy.

## How to Contribute

### Reporting Issues

- Use GitHub Issues to report bugs or suggest features
- Include clear descriptions and reproduction steps
- Be respectful and constructive

### Development Setup

```bash
# Clone the repository
git clone https://github.com/colleenpridemore/Molten.git
cd Molten

# Install dependencies
pip install -r requirements.txt

# Install in development mode
pip install -e .

# Run tests
pytest tests/
```

### Code Guidelines

1. **Python Style**: Follow PEP 8 guidelines
2. **Type Hints**: Use type annotations for function signatures
3. **Documentation**: Add docstrings for new functions/classes
4. **Tests**: Include tests for new features
5. **Empathy**: Consider cognitive accessibility in UI/UX

### Testing

```bash
# Run all tests
pytest tests/ -v

# Run with coverage
pytest tests/ --cov=openclaw_identity --cov=empathy_engine

# Run specific test categories
pytest tests/ -m unit
pytest tests/ -m empathy
pytest tests/ -m security
```

### Submitting Changes

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Make your changes
4. Run tests and linting
5. Commit with clear messages
6. Push to your fork
7. Open a Pull Request

### Pull Request Guidelines

- Describe what changes you made and why
- Reference related issues
- Ensure all tests pass
- Update documentation if needed
- Keep changes focused and minimal

## Code of Conduct

### Our Pledge

We pledge to make participation in this project a harassment-free, empathetic experience for everyone, with special consideration for:

- Neurodivergent contributors
- People of all backgrounds and identities
- Those who think and communicate differently

### Expected Behavior

- Use welcoming and inclusive language
- Respect differing viewpoints and experiences
- Accept constructive criticism gracefully
- Focus on what's best for the community and living beings
- Show empathy towards others

### Unacceptable Behavior

- Harassment or discriminatory language
- Manipulation or gaslighting
- Attempts to bypass safety features
- Code that could harm users or living systems
- Disrespect of cognitive differences

## GHCP Sentinel Compliance

When contributing code that interacts with users:

- Implement harm detection appropriately
- Maintain resonance with biocentric values
- Respect user boundaries and autonomy
- Consider impact on cognitive well-being

## Security

If you discover a security vulnerability:

1. **Do NOT** open a public issue
2. Email the maintainers privately
3. Provide details about the vulnerability
4. Wait for acknowledgment before disclosure

## Recognition

Contributors will be recognized in:

- CONTRIBUTORS.md file
- Release notes
- Project documentation

## Questions?

- Open a GitHub Discussion
- Check existing documentation
- Review the roadmap and guides
